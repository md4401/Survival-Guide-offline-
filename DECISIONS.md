# DECISIONS

Where the spec (v1.1) conflicts or is silent, the simplest option was chosen and logged here.

| # | Topic | Decision |
|---|-------|----------|
| 1 | "Faça agora" step count | Spec §4 says ≤5 steps, but both spec example guides (campsite: 10, filter: 8) exceed it. The validator allows up to **10** steps; the 12-words-per-step rule is enforced. PT example steps were shortened to meet 12 words (meaning preserved). |
| 2 | Example guides status | Published (visible) but flagged `needsReview: true` with level `draft` and a source placeholder: the Mapa says they are drafts that need review + registered source. UI shows a "Needs review" badge. |
| 3 | Other guides | 8 scenarios, water, first-aid and kit entries are generated **drafts** (`scripts/gen-stubs.ts`): title only, no steps, hidden unless Developer mode is on. No medical/safety facts were invented. |
| 4 | Country data | npm `world-countries` (ODbL, attribution required) converted at build time to `src/generated/countries.json`. Names/languages/currencies are localized via `Intl` on device. **Population and time zones are not in that dataset** and are not invented: they are omitted until a source is provided. |
| 5 | Climate (44 cities) & emergency numbers | Structure + small sample only, flagged "needs review". Real data must come from official sources. |
| 6 | Native | Capacitor is configured only (`capacitor.config.ts`); `android/` and `ios/` are not generated (cannot be built here). |
| 7 | Routing | Hash routing (works from `file://`/Capacitor/no server). |
| 8 | Locale stubs | es/fr/ar/hi/zh locale files exist but are empty; they fall back to English per key. `ar` switches `dir="rtl"`. |
| 9 | Settings persistence | Single `kv` row in IndexedDB (Dexie). No localStorage, no network. |
| 10 | Premium | `FLAGS.premium=false`; only interfaces under `src/interfaces/`. Vital content can never be `plan: premium` (validator enforces). |
| 11 | Triage | Spec asks 3 questions in ≤3 taps from the icon. Implemented as **one** question ("What is happening?", life-threatening options first) so icon → help → situation = 3 taps. "Where are you?" is not asked. If the target guide is an unpublished draft, the app shows emergency numbers and an explicit "under review" notice instead of inventing content. |
| 12 | Emergency numbers | Only the numbers printed in the spec (BR, EU 112, US/CA 911, GB 999, AU 000, BR mental health 188). Flagged as sample/needs review; other countries show "look up local number". |
| 13 | GPS / flashlight | Web APIs (Geolocation, camera torch via `getUserMedia`, Wake Lock) work in the PWA and the Capacitor WebView. If the device has no camera torch, a full-screen light with adjustable brightness is used. Native Capacitor plugins are a later optimization. |
| 14 | Sun/Moon accuracy | Sun: NOAA equations (tested within ±4 min vs published London values; polar day/night handled). Moon: mean synodic month, phase timing ±~1 day, labelled approximate in the UI. |
| 15 | Almanac time zone | Times are shown in a user-selected IANA zone (default device) using `Intl`; no zone tables shipped. Country → coordinates uses the dataset's country center, not the capital. |
| 16 | Climate / tables | Climate = 3 sample cities, rounded, flagged unverified. Tables (Beaufort, Saffir-Simpson, UV, quake classes, Morse, Roman) are standard public scales flagged "needs review". Units, hurricane/Mercalli detail deferred. |
| 17 | Country data gaps | Population and per-country time zones are not in `world-countries`; omitted rather than invented. Capital names are shown as in the dataset (not localized). |
| 18 | Holidays | Brazil only (fixed + Easter-based dates), flagged for verification. Islamic/Hebrew/Chinese/Persian dates come from the device `Intl`. |
| 19 | Kit quantities | `src/data/kits.ts` quantities (e.g. 3 L water/person/day, 3 meals/person/day) are **placeholders** for the calculator and flagged "needs review" in the UI. Chlorine dosing and consumption-by-climate calculators are not implemented (safety-critical, no source yet). |
| 20 | Onboarding | Non-blocking: a card on Home opens the 5-question flow; skipping marks it done. Emergency access never waits on onboarding. Profile only adds conditional kit items (with a "why am I seeing this" note); region-based rules need data. |
| 21 | Plan gating | `canAccess()` (src/content/access.ts) always allows `vital`; premium is unreachable while `FLAGS.premium=false`. Interfaces for license, AI assistant, voice reading and pack updates are contracts + no-op stubs. |
| 22 | Emergency numbers | 193 countries from npm `emergency-numbers` (MIT, derived from a Wikipedia list). **Community data, shown as unverified.** Numbers stored as integers lose leading zeros (AU = `0`), so zero values are dropped and the spec §5.1 numbers (BR, EU, US, CA, GB, AU) override and are labelled "sample/needs review". |
| 23 | Population / time zones | Added from npm `country-json` (MIT; 236/250 matched by name, rest left empty) and `countries-and-timezones` (MIT). Approximate. |
| 24 | Climate | No source was reachable (open data hosts blocked in the build sandbox), so the 3 sample cities remain; 44 cities need a source. |
| 25 | Crisis mode | Start from Home: scenario → day counter, current timeline stage, link to scenario guide + 72 h checklist, battery level/estimate, diary, battery saver on (restored at the end), restock list. Guides may carry an optional `timeline` (validated ≤12 words/step); no timeline content was written. The update prompt is never shown during a crisis. |
| 26 | Water calculators | Water need and chlorine dose use **placeholder** parameters (flagged). Chlorine maths is unit-tested (mL = mg/L × L ÷ (% × 10)); the default target (5 mg/L), 20 drops/mL and the 30-minute wait are assumptions to be reviewed. |
| 27 | Premium pieces | Implemented but **off**: offline Ed25519 license verification (no public key bundled → nothing verifies), read-only 30-day grace, never blocks during a crisis; device-voice reading (shown only in Developer mode); checksum-verified pack updater (inert: no server URL). Purchases/restore need a store plugin and backend. |
| 28 | AI assistant | Optional, **not bundled** in the app or core. The user chooses a model (tiers per spec §6.9 + custom Hugging Face repo) and confirms the download; the runtime (`@huggingface/transformers@3.8.1`) is loaded from jsDelivr only then and cached by the service worker. Answers are anchored: life-risk words open the reviewed guide with no AI; dose/diagnosis/weapons are blocked; only published guides are context; the reply must cite a guide and use only numbers present in it, else only the guides are shown; ≤200 words; AI off in Crisis mode by default. Model repo ids and sizes are best-effort and unverified (no access to Hugging Face from the build sandbox); the pipeline was tested with a mocked runtime. |
| 29 | Translations | es/fr/ar/hi/zh have ~170 essential UI keys (navigation, emergency, triage, guide structure, settings, crisis); other keys fall back to English per key. Machine-assisted drafts: need native-speaker review. Language selector marks them "beta". Guide content exists only in en/pt (others show English with a notice). |
| 30 | Native projects | `android/` and `ios/` generated by Capacitor with camera/location/vibrate permissions; not built or run here. |
| 31 | Draft guide text | `scripts/fill-drafts.py` filled the 22 draft guides (8 scenarios, water ×3, first aid ×9, kits) with conservative text from widely published public guidance (e.g. hands-only CPR, direct pressure for bleeding, STOP rule, 30-30 lightning rule, boil 1/3 min, SODIS). They remain `status: draft`, `needsReview: true`, source "to verify", visible **only in Developer mode**, per the original instruction; triage and the AI assistant still ignore them. Publishing any of them requires professional review and a registered source. |
| 32 | Climate zones / map | 12 zones are **qualitative** (no numbers) and flagged for review. The "climate map" colors country centers by **latitude band only** (tropical/subtropical/temperate/subpolar/polar), declared as an approximation, not real climate zones. "World in numbers" is computed from the bundled country data; "records" were left out (need a source). |
| 33 | Compass | Uses `deviceorientationabsolute` / iOS `webkitCompassHeading` with the iOS permission prompt; explains when no sensor exists. Untested on real hardware. |
| 34 | Backup | AES-GCM + PBKDF2-SHA256 (210 000 iterations) file the user keeps; covers favorites, history, counters, checklists, notes, settings/profile/family plan/crisis. AI install state is excluded. Wrong password and tampering both fail the GCM tag; an import replaces local data atomically (Dexie transaction). Lost password = unrecoverable. |
| 35 | Error reports | "Report an error" stores reports on the device only (listed/copyable in Settings). Sending needs a server: `REPORT_ENDPOINT` is `null`; sending also requires online + user consent (tested). |
| 36 | Guides in es/fr/ar/hi/zh | The 24 guides (22 drafts + 2 examples) exist in all 7 languages as **machine-assisted drafts** (`scripts/guides-i18n/*.py` → `scripts/gen-guide-langs.py`). The validator forces `status: draft` + `needsReview: true` for those languages, so they are **never shown to users**: a Spanish/French/Arabic/Hindi/Chinese user sees the published English guide with a notice; Developer mode shows the translated draft. Even the 2 example guides are drafts in those languages. Chinese step length is counted as ~2 characters per word. |
| 37 | Readiness score | Spec §6.3 weights (water 20, food 15, health 20, energy 10, comms 10, shelter 10, docs 10, knowledge 5). Each area = share of checked 72 h kit items (comms also counts a filled family plan; knowledge = share of visible vital guides opened, since there are no lessons yet). The next step is the unchecked item with the most points per item. Guidance only. |
| 38 | AI retrieval hardening | The offline evaluation (`npm run eval:ai`, 60 questions en/pt) exposed noise: function words matched every guide and typo-only matches grounded off-topic answers. Fixed with stop-words, prefix/fuzzy only on longer terms, and requiring an exact/prefix term match (`exact`) before a guide may be used as context. Results: guards 100%, retrieval 100%, off-topic → no result 75% (thresholds enforced in `verify`). Generation quality is NOT measured by it: use Developer mode → Assistant → "Run evaluation" with an installed model. |
| 39 | Scenario timelines | `timeline` (10 min … 30 d) written for the 8 scenarios in en/pt as drafts (they appear only in Developer mode with the drafts); not translated to es/fr/ar/hi/zh. |
| 40 | Legal drafts | `docs/PRIVACY.md` and `docs/TERMS.md` (en+pt) describe the real behaviour (no collection, opt-in AI download, permissions) and carry placeholders for a lawyer; the app has an About page with the same facts. |
| 41 | UI translations | es/fr/ar/hi/zh now cover 508 of 580 keys (`scripts/ui-i18n/*.txt` + `merge.py`); the remaining 72 (optional AI screens, long climate-zone descriptions) fall back to English. Machine-assisted drafts, native review needed. |
